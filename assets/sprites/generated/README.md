# Generated Sprite Assets

This folder contains normalized 2D animation strips for the ship/enemy set.

- Frame size: `128x128`
- Anchor: centered at `64,64`
- Strip layout: `4` horizontal frames per PNG
- Metadata: see `sprite_manifest.json`
- Preview: see `sprite_preview_sheet.png`

The current game scenes still use procedural Sprite2D drawing, so these strips are
ready for swap-in or SpriteFrames import work when you want to wire them up.
