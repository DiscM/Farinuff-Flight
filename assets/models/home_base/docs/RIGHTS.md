# Rights and provenance

The Wayfarer Homeport models, surface and emission atlases, and rigid animations are original local artwork authored in Blender for Farinuff Flight. No third-party model or texture library and no paid asset-generation provider were used for this delivery.

The delivery records `NOASSERTION` as its SPDX license value, following the project's existing original-art provenance convention. This document does not assign ownership or create a new public redistribution license. The project owner controls the project's release terms.

The editable Blender source, exported GLBs, atlas PNGs, and validation helper support review, rebuilding, and use within this project. Existing code and other game assets retain their existing terms and third-party notices.

The exact request, source paths, coordinate conventions, and static validation scope are recorded in `provenance.json`. File digests and technical measurements are recorded by `tools/check_home_base_assets.py`; rendering and gameplay verification remain separate evidence.
