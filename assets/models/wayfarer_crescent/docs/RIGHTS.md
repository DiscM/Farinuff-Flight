# Rights and provenance

Original procedural geometry, pixel textures, rigid machinery animation and spacecraft motion authored locally in Blender for Farinuff Flight. The source design is the user-selected Crescent Harbor spacecraft mockup created with built-in image generation in this task. No external mesh library, texture library or paid 3D-generation service was used.

The Blender source, modular GLBs and full composition are new artifacts. Existing home-port game assets retain their original bytes and release terms. The delivery manifest records the reference image hash, output hashes, Blender version, source scripts and animations.
