# Rights and provenance

The Voxel Frontier geometry, atlas artwork, and Blender authoring recipe were created locally for Farinuff Flight in this task. No third-party model library, downloaded mesh, or paid asset-generation provider was used for this set.

No repository-wide license grant was present when this package was prepared. The package therefore records `NOASSERTION` for its SPDX license field. This documentation does not assign ownership or grant a new public redistribution license; the project owner controls the project's release terms.

The package can be used to review, rebuild, and integrate the commissioned assets into this project. Before publishing the assets as a standalone public library, the project owner should choose and supply the intended license. This is a rights record, not a claim that the artwork is MIT, CC0, or public domain.

Existing game code and shaders included as integration references retain their existing terms. The Pixel Planets-inspired enemy shader credits Deep-Fold's MIT-licensed PixelPlanets shaders; its full upstream notice is included at `effects/shaders/PixelPlanets/LICENSE`. This is the only third-party-derived integration component identified in this asset delivery. The original geometry and atlas do not incorporate third-party models or textures.

Other third-party components elsewhere in the game retain the notices recorded in the repository's `THIRD_PARTY_NOTICES.md`; they are not relicensed or bundled merely by reference in this package.
