# Rights and provenance

The boss geometry and animation in this set were authored locally in Blender for Farinuff Flight. The shared surface atlas is original artwork from the preceding Voxel Frontier task. No third-party model library or paid generation provider was used.

No repository-wide public license grant was present when this package was prepared. Its SPDX metadata therefore records `NOASSERTION`; this document does not assign ownership or grant a new public redistribution license. The project owner controls release terms.

Included integration code retains its existing project terms. The included Pixel Planets-derived shader’s Deep-Fold MIT notice is supplied alongside the integration sources at `effects/shaders/PixelPlanets/LICENSE`. That notice applies to the identified shader reference; it does not relicense the original boss geometry, atlas, or other project code.
